GOV.UK rate limit: 10 req/sec. Both windows are well within limits. Content API calls are identical regardless of window — only countries that actually changed get fetched. The difference is Search API polling frequency.

Key Takeaways

  • Volume is low: Even the busiest country (Mexico) only changes ~once per week. ASAP notifications will not overwhelm users.
  • Daily and ASAP are near-identical in volume: Since changes happen less than once/day per country, both deliver the same number of notifications — just with different latency.
  • Weekly is the real digest: Most countries bundle 1-3 changes per weekly digest.
  • API usage is dominated by Search polling: Content API calls (~1,800/yr) are fixed. Moving to 15-min ASAP adds ~26k Search calls/year (~100/day), well within the 10 req/sec limit.
  • Peak day (211 changes) is rare: Likely a bulk template update. The rate limiter handles it gracefully within a single Lambda invocation.
